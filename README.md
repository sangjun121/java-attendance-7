# java-attendance-precourse - [BE] 조상준

# 1. 어플리케이션 기능 명세서
- 모든 예외 발생시 [ERROR] 메시지를 출력하고, 어플리케이션은 종료된다.

## 0. 어플리케이션 실행 부트스트랩
- [ ] 금일 날짜를 저장한다.
- [ ] 각 요일의 교육 시작 시간을 저장한다.
- [ ] 크루와, 12월 출석기록 csv 파일을 등록한다.

## 1. 메인페이지 기능
- [ ] 사용자에게 기능 번호를 입력받는다.
  - 1,2,3,4,Q 중에 하나를 입력할 수 있다.
  - [ ] 검증1. 월~금요일이 아닌 경우, 1,2번의 출석 확인,수정 기능은 사용할 수 없다.
    - 예: [ERROR] 12월 14일 토요일은 등교일이 아닙니다.
  - [ ] 검증2. 잘못된 항목인 경우 아래 메시지를 출력한다.
    - 예: [ERROR] 잘못된 형식을 입력하였습니다.

## 2. 출석 확인 기능
- [ ] 사용자 닉네임을 입력 받는다.
  - [ ] 검증1. 등록되지 않은 닉네임의 경우 예외를 발생시킨다.
    - 예: [ERROR] 등록되지 않은 닉네임입니다.
  - [ ] 검증2. 이미 출석한 경우, 수정 기능을 안내하는 메시지를 출력하고 메인페이지로 돌아간다.
    - 예: [ERROR] 이미 출석을 확인하였습니다. 필요한 경우 수정 기능을 이용해 주세요. 
- [ ] 사용자에게 등교 시간을 입력 받는다.
- [ ] 금일 교육 시작 시간을 불러온다.
  - [ ] 검증1. 캠퍼스 운영시간이 아닌 경우, 아래 메시지를 출력한다.
    - 예: [ERROR] 캠퍼스 운영 시간에만 출석이 가능합니다.
- [ ] 사용자를 해당 날짜에 등교 시간를 기반으로 출석을 저장한다.
- [ ] 출석 완료 메시지를 출력하고 메인페이지로 돌아간다.

## 3. 출석 수정 기능
- [ ] 출석을 수정하려는 사용자 닉네임을 입력 받는다.
    - [ ] 검증1. 등록되지 않은 닉네임의 경우 예외를 발생시킨다.
- [ ] 출석을 수정하려는 날짜(일자)를 입력받는다.
  - [ ] 검증1. 미래 날짜로 수정하는 경우 아래 메시지를 출력한다.
    - 예: [ERROR] 아직 수정할 수 없습니다.
  - 
- [ ] 수정할 시간을 입력한다.
- [ ] 수정할 시간을 기반으로 지각, 출석 상태를 확인하고, 출석을 저장한다.
- [ ] 수정 완료 확인 메시지를 출력하고 메인페이지로 돌아간다.

## 4. 크루별 출석 기록 확인 기능
- [ ] 출석을 조회하려는 사용자 닉네임을 입력 받는다.
    - [ ] 검증1. 등록되지 않은 닉네임의 경우 예외를 발생시킨다.
- [ ] 크루의 이번달 출석 기록을 조회한다.
  - 출석 기록이 존재하지 않는 경우 "--:--"로 출력하고, 출석상태를 "결석"으로 표기한다.
- [ ] 크루의 출석 상태를 기반으로 경고, 면담, 제적 대상 여부를 조회한다.
  - 이때, 3회 지각을 결석 1회로 간주한다.
- [ ] 크루의 이번달 출석 기록을 출력한다.
- [ ] 크루의 출석 상태와 대상 여부를 출력하고, 메인페이지로 돌아간다.

## 5. 제적 위험자 확인 기능
- [ ] 이번달 제적 위험자(경고, 면담, 제적)를 조회한다.
- [ ] 제적 -> 면담 -> 경고 상태로 정렬하고, 출석 상태가 같으면 닉네임으로 오름차순 정렬한다.
- [ ] 제적 위험자의 이름, 출석 상태, 대상 여부를 함께 출력한다.

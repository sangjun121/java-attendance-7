# java-attendance-precourse - [BE] 조상준

# 1. 기능 명세서

## 1. 어플리케이션 실행 부트 스트랩
- [x] 오늘 날짜를 저장한다.
- [x] 크루들의 출석 현황이 담긴 csv파일을 저장한다.

## 2. 메인 페이지 기능
- [x] 메인페이지를 출력한다.
- [x] 사용자에게 기능 번호를 입력받는다.
    - 기능의 번호는 1~4와 Q만 입력 가능하다.
    - [x] 올바르지 않은 기능을 입력했을 때 예외가 발생한다.
        - [ERROR] 잘못된 형식을 입력하였습니다.

## 3. 출석 확인 기능

- [x] 금일 날짜가 월~금요일인지 확인한다.
    - [ERROR] 12월 14일 토요일은 등교일이 아닙니다.
- [x] 닉네임을 입력 받는다.
    - [ ] 검증. 등록되지 않은 닉네임이면 예외가 발생한다.
      - [ERROR] 등록되지 않은 닉네임입니다.
- [x] 등교 시간을 입력 받는다.
    - [ ] 검증. 올바른 시간 형태가 아닌 경우 예외가 발생한다.
      - [ERROR] 잘못된 형식을 입력하였습니다.
    -[ ] 검증. 캠퍼스 운영 시간이 아닌 경우 예외가 발생한다.
      - [ERROR] 캠퍼스 운영 시간에만 출석이 가능합니다.
- [x] 금일 날짜로 출석이 존재하는 경우, 수정 유도 문구를 출력한다.
    - [ERROR] 이미 출석을 확인하였습니다. 필요한 경우 수정 기능을 이용해 주세요.
- [x] 금일 날짜의 출석을 등록한다.
- [x] 출석 완료 문구를 포멧팅하여 출력한다.

## 4. 출석 수정 기능
- [ ] 닉네임을 입력 받는다.
    - [ ] 검증. 등록되지 않은 닉네임이면 예외가 발생한다.
        - [ERROR] 등록되지 않은 닉네임입니다.
- [ ] 수정하려는 날짜(일)를 입력 받는다.
    - [ ] 검증. 올바르지 않은 일자 형태인 경우 예외가 발생한다.
        - [ERROR] 잘못된 형식을 입력하였습니다.
      - [ ] 검증. 미래 일자인 경우 예외가 발생한다.
        - [ERROR] 아직 수정할 수 없습니다.
- [ ] 변경 등교 시간을 입력 받는다.
    - [ ] 검증. 올바른 시간 형태가 아닌 경우 예외가 발생한다.
        - [ERROR] 잘못된 형식을 입력하였습니다.
    - [ ] 검증. 캠퍼스 운영 시간이 아닌 경우 예외가 발생한다.
      - [ERROR] 캠퍼스 운영 시간에만 출석이 가능합니다.
- [ ] 기존 출석 현황을 제거하고, 새 출석 현황을 등록한다.
- [ ] 수정 전 날짜와 현재 날짜를 함께 표기한 수정 완료 문구를 출력한다.

## 5. 출석 기록 확인 기능
- [ ] 닉네임을 입력 받는다.
    - [ ] 검증. 등록되지 않은 닉네임이면 예외가 발생한다.
        - [ERROR] 등록되지 않은 닉네임입니다.
- [ ] 크루의 닉네임을 기반으로 출석 현황을 조회한다.
- [ ] 각 일자에 해당하는 출석/지각/결석 상태를 함께 조회한다.
- [ ] 출석/지각/결석 상태를 기반으로 재적/면담/경고 상태를 조회한다.
- [ ] 출석 현황을 출력한다.
- [ ] 총 출석/지각/결석 횟수를 출력한다.
- [ ] 재적/면담/경고 대상자 여부를 출력한다.

## 6. 제적 위험자 확인 기능
- [ ] 출석부 현황을 조회한 후, 각 크루의 결석, 지각 횟수를 조회한다.
- [ ] 지각 3회를 1결석으로 변환하여, 총 결석 상태를 기반으로 재적/면담/경고 상태를 조회한다.
- [ ] 제적, 면담, 경고 대상자 순으르 출력하고, 동일한 경우 이름 오름차순으로 정렬한다.
